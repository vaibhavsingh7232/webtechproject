🛍️ Full-Stack E-Commerce Website

This repository contains the source code for a fully functional e-commerce website built as a practical web development project.
The platform allows users to browse products, view product details, register/login, and contact the vendor for orders.

🚀 Project Overview

The objective of this project was to design an end-to-end shopping platform with:

✔ A product showcase page
✔ User account creation & login system
✔ Contact / enquiry module
✔ Responsive multi-page frontend
✔ Integrated backend for dynamic actions

This project helped strengthen real-world skills in web development, authentication and server integration.
